## 📌 Featured Projects

### 🎮 [Optimizing Blackjack Strategies with Reinforcement Learning](https://github.com/Haarshiith/blackjack-rl)
- Implemented **SARSA** and **Double Q-Learning** agents from scratch.
- Created a full blackjack simulation environment with rule variations (e.g., No Face Cards, Blackjack Pays 6:5).
- Developed an advanced state representation with a complete point-count system for card counting.
- Published a **6-page IEEE-format paper** with experimental analysis.

### 🎯 [Sensor Fusion using Particle Filters](https://github.com/Haarshiith/particle-filter-sensor-fusion)
- Built a **particle filter** from scratch to track multiple non-distinguishable objects.
- Designed a custom state-transition model for projectile trajectories.
- Integrated **K-Means clustering** to extract unique object states from multimodal distributions.

### 🚗 [Driver Drowsiness Detection System](https://github.com/Haarshiith/driver-drowsiness-maixdock)
- Deployed an embedded **CNN-based** system with **98% accuracy** using multi-sensor inputs.
- Implemented **real-time alerts** via Ethernet and geospatial logic.
- Built with **C programming** on **Maix Dock** hardware.

### 🏠 [Voice-Controlled Home Automation](https://github.com/Haarshiith/smart-home-voice-control)
- Developed a **C + Arduino** smart home solution for elderly and disabled users.
- Integrated **voice, motion, and text** control with automated scheduling for energy efficiency.
- Android app for seamless user interaction.
